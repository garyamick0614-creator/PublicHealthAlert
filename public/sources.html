Source registry

Each source is tagged with its access type and last-scraped timestamp. Health is computed from the latest run log.

Methodology

How raw publisher feeds become rows on the dashboard.

Every night at 01:00 ET a scheduled task on the operator PC runs scripts/scrape.mjs. Each connector below is invoked in parallel and emits rows into a normalized event schema. Raw per-source output is archived under data/YYYY-MM-DD/ for full-day audit.

At 02:00 ET the verifier runs scripts/verify-publish.mjs. It validates that:

  • The 01:00 scrape file exists and is fresh (≤ 6h old).
  • At least one source produced events.
  • Total event count is above the configured minimum.
  • No fatal parser errors were logged for the day.

If verification passes, the new feed is written to public/data/events.json, committed to GitHub, and pushed to Netlify. If verification fails, the previous publish is republished with a status: stale flag — the site never goes empty.

Field-level normalization

Each connector returns rows in this shape: id, source, source_url, report_date, virus, event_type, status, origin_country, origin_setting, current_spread, us_pathway, us_cases, title, summary, region, latitude, longitude, scraped_at.

Virus, status, event-type, and U.S. pathway are detected by deterministic keyword patterns over the title + summary. Country detection only scans the title to avoid false positives from incidental mentions in summary text. The full pattern set is open-source in scripts/lib/schema.mjs.

Why the keyword approach? All five core publishers emit human-readable prose. A keyword classifier is honest about its precision: it tags only what it's confident in, and leaves uncertain fields null rather than guessing. Future iterations may add per-source structured extractors (e.g. WHO DON's bracketed country fields) — those will land in source-specific connectors, not as a global heuristic.

Access tags

public — confirmed reachable without authentication. key_required — endpoint requires a credential we do not architect against. unknown — access status not yet verified.
